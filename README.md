# Unit 2 — What Are They Making?
موقع ثابت للصفحة 14: Conversation وAbout You. الإنجليزية أساسية والعربية مساعدة.

## الملفات
- index.html: صفحة الموقع.
- styles.css: التصميم المتجاوب والحركة مع احترام prefers-reduced-motion.
- app.js: الحوار والأنشطة والحفظ المحلي وتشغيل تضمين YouTube.
- .nojekyll: للنشر الثابت على GitHub Pages.

## الرفع إلى GitHub Pages
1. فك ضغط الحزمة.
2. أنشئ مستودعًا في GitHub، ثم اختر Add file → Upload files.
3. ارفع محتويات المجلد بحيث يكون index.html في جذر المستودع، وليس داخل مجلد إضافي، ثم Commit changes.
4. افتح Settings → Pages → Build and deployment.
5. اختر Deploy from a branch، ثم main و/(root)، ثم Save.
6. بعد اكتمال النشر افتح الرابط الذي يظهر في Pages.

كل المسارات المحلية نسبية وتعمل تحت مسار المستودع. لا يلزم npm أو خادم خلفي أو حساب للطالب. يمكن معاينة الملفات محليًا بخادم ثابت مثل `python3 -m http.server 8000` ثم فتح http://localhost:8000.

## الاستخدام
- قائمة التنقل تنتقل إلى أقسام الصفحة.
- كل سؤال فهم يقبل اختيارًا واحدًا، ثم يعرض التصحيح. Try Again يعيد أسئلة الفهم فقط.
- Switch Roles يبدل دور الطالبين.
- أسئلة About You تُجاب شفهيًا؛ فتح السؤال يعرض أمثلة اختيارية، لا تقييم لصحتها الشخصية.
- الشرح العربي قابل للإخفاء. أمثلة Real Talk وإجابات About You موضحة بعنوان «توضيح إضافي».
- التقدم والاختيارات والأدوار وتفضيل العربية محفوظة في LocalStorage في هذا المتصفح فقط. عند تعذر الحفظ تظل الأنشطة متاحة، وتظهر رسالة واضحة.

## الصوت والخصوصية
مشغل YouTube للفيديو mAyXQgY1PtM مع أدوات التحكم الأصلية. لا يوجد تشغيل تلقائي. يحتاج الإنترنت، وقد تمنع إعدادات المتصفح أو مالك الفيديو التضمين. يظهر رابط فتح الفيديو دائمًا، وتعرض أخطاء API أو مهلة التحميل رسالة بديلة. لا يمكن لحدث تحميل iframe وحده إثبات تشغيل الصوت؛ لا يُستخدم لهذا الغرض. الموقع لا يرسل إجابات الطالب، لكن تضمين YouTube يتصل بخدمة خارجية تخضع لسياساتها.
